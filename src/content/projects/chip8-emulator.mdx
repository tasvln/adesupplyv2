Built a complete **CHIP-8 virtual machine** from scratch in Rust, recreating the original memory model, registers, timers, and instruction set through a classic fetch-decode-execute cycle. The emulator renders a 64x32 display, maps keyboard input to the CHIP-8 hex keypad, and drives audio through a sine wave beeper.

The project was a systems programming exercise in low-level CPU emulation, using `minifb` for windowing and `rodio` for sound output.
